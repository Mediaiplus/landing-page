# MEDIAIPLUS — Product Landing Page

Static landing page for MEDIAIPLUS products (FiCRO, MediC, MedidraftAI, MediScholar).

## Deploy on GitHub Pages

1. Push the contents of this folder to your repository root (or a `docs/` folder).
2. In the repo: **Settings → Pages → Source** → select the branch (and `/ (root)` or `/docs`).
3. The page will be served at `https://<user>.github.io/<repo>/`.

No build step required — plain HTML/CSS with two Google Fonts (Poppins, Noto Sans KR).
